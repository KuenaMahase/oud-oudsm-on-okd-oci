# Project artifacts

This directory contains first-class historical artifacts from the OUD/OUDSM
deployment work:

- `presentation/`: sanitized PowerPoint, PDF, transcript-linked slide renders
- `architecture/`: architecture and NFS design graphics
- `source-documents/`: sanitized conversions of working documents and runbooks
- `source-notes/`: sanitized design and troubleshooting notes
- `source-manifests/`: historical NFS CSI test manifests

See `docs/23-source-artifact-register.md` for the inclusion and exclusion policy.
